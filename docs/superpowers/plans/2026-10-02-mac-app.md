# VoiceVision Mac Implementation Plan

Goal: a native local accessibility companion that works across ordinary desktop apps.
Architecture: Swift package with testable settings/command core and native UI/platform services. Existing web app and extension remain supported.
Tech: Swift, SwiftUI, AppKit, ApplicationServices, AVFoundation, Speech; macOS13+.

- [x] Core: desktop/Sources/VoiceVisionCore/Settings.swift; tests for normalization, explicit need commands and undo. Run swift test in desktop.
- [x] Platform: desktop/Sources/VoiceVisionMac/Platform.swift for click-through per-screen overlays, explicit text access, read-aloud and optional on-device speech. No private APIs or screen recording.
- [x] UI: desktop/Sources/VoiceVisionMac/App.swift for window/menu-bar controls, reader, privacy and recovery. Permission errors must offer alternatives.
- [x] Package: desktop/Package.swift, desktop/build-app.sh and desktop/Info.plist. Build release, assemble VoiceVision.app, ad-hoc sign and verify. Save installable ZIP to Downloads.
- [x] Verify app process launch; UI inspection blocked by native bridge closure. Review bounded state/platform behavior, document untested system permissions/distribution limits; commit and push meaningful segments.
