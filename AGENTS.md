# VoiceVision agent instructions

Read this and CLAUDE.md before changes. Current product supersedes hackathon PRD/BUILDPLAN/SKILLS examples.

## Product constraints
- Reading/accessibility tools, not clinical treatment. Review docs/EVIDENCE.md before changing condition-related behavior or claims.
- Blindness in one eye differs from visual-field loss. No center/peripheral/half-screen masks exposed as assistance or clinical simulation.
- Condition-only commands leave settings unchanged. Explicit needs like larger text, contrast, glare and motion controls are user choices.
- Optional color adjustments never promise vision correction. Warm tint never promises eye protection or treatment.
- Voice remains optional; typing/manual controls work without Gemini. Cloud parsing is off until user opts in. Browser speech may separately use its provider.
- Undo/reset cancel pending interpretation. Never apply an obsolete response.

## Mac companion
- desktop/: Swift6 package with core settings/history/tests and native SwiftUI/AppKit app. Build with desktop/build-app.sh; test with swift test --package-path desktop.
- No cloud, screen recording or automatic clipboard access. Only explicit selection/paste and on-device voice; secure fields rejected. Closing controls cancels capture. Save preferences, never passages; overlays disabled each launch.
- Undo includes activation. Do not claim native UI/permissions or notarization without actual verification. See desktop/README.md.

## Architecture
- Next.js App Router, React, TypeScript strict. Follow package-lock.json: npm.
- src/types/index.ts: shared command and FilterState.
- src/lib/intent.ts: framework-free local parser.
- src/lib/command.ts: validation and assistive safety guard for untrusted commands.
- src/lib/filters.ts: shared CSS/SVG engine and reading styles.
- src/lib/persistence.ts: validated saved state; legacy masks stripped.
- src/hooks/: React state, cancellable interpretation, speech recognition.
- src/app/page.tsx: reading workspace. src/components/: labelled controls and optional educational color comparison.
- src/app/api/interpret/: server-only Gemini proxy, bounded input, output validation, per-instance quota guard.
- src/extension/content.ts: shared engine and extension message handling.
- extension/popup.{html,css,js}: manual/typed/voice controls and explicit cloud opt-in.
- extension/content.js: generated by npm run build:ext; never hand-edit, commit generated bundle.

## Rules
- SDK @google/genai, response.text property. GEMINI_API_KEY only in server API code.
- CSS filters compose through buildFilterString; SVG defs must exist first.
- color-interpolation-filters="linearRGB" on color matrices.
- Fixed overlays append to document.documentElement because filtered body creates containing block.
- Reading preferences must apply to dynamic text, preserve original styles, exclude controls and avoid nested scaling.
- Validate external responses/messages and numeric bounds. Restore settings through normalizeFilterState.
- Use engineering-rules for applicable code. Preserve unrelated changes. No filler comments or speculative abstractions.

## Verification
npm test; npm run lint; npx tsc --noEmit; npm run build; npm run build:ext.
Check keyboard, narrow screens, 200% zoom, reduced motion, microphone denial, reset/late reply, persistence and extension behavior. Report actual evidence and limitations. Do not claim clinical effectiveness, assistive-technology validation, deployment or store publication without verification.

## Extension protocol
GET_STATE; APPLY_COMMAND {command,expectedRevision?,transcript?}; SET_READING {key,value}; UNDO; REPLACE_STATE {state}; TOGGLE_FILTER {key}; SET_INTENSITY {key,value}; vv:scope {scope}; vv:interpret {transcript}.
Scope site/global. Unknown local phrases return revision for stale cloud guard. Mic port voicevision-mic sends START/STOP and returns start/end/result/error.
